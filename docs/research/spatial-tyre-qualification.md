# Пространственная шина: протокол qualification W28

Статус: **source_written; numerical validation pending V04/V06**. Сборка,
запуски, измерения и подбор коэффициентов при написании не выполнялись.

## Что означает профиль

`native/tests/spatial/data/tyre_profiles.json` сохраняет идентичность шин
исходной конфигурации: Magic Mary 29×2.4 спереди и Hans Dampf 27.5×2.4 сзади.
Все семейства нормальных, продольных, боковых, camber, aligning и relaxation
коэффициентов имеют статус `provisional`, ноль измерений и `digest: null`.
Параметры `synthetic_spec` в тестах служат физическим проверкам и не являются
калибровкой этих моделей шин. Хэш разрешённых коэффициентов в runtime нужен
для идентичности состояния; сам по себе он не повышает provenance.

Данные W03 `tests/fixtures/spatial3d/references/tyre-lateral.json` относятся
к другим велосипедным шинам и помечены `cross_check_only`. Тест сохраняет
разделение: независимая fit/withheld проверка этих строк даёт RMS только для
этого набора; для MTB измеренный domain отсутствует. Каждый sample матрицы
MTB поэтому имеет статус `exploratory`, даже если физические инварианты прошли.
Нельзя переименовывать эти строки в измерения Magic Mary или Hans Dampf.

## Матрица и последовательность

| Параметр | Значения |
|---|---|
| Нормальная нагрузка | 100, 300, 600, 900 N на колесо |
| Давление | 1, 1.5, 2 bar |
| Скорость | 0, 0.1, 1, 3, 8 m/s |
| Продольное проскальзывание κ | 0, ±0.02, ±0.1, ±0.3 |
| Угол увода α | 0, ±1°, ±3°, ±6° |
| Camber γ | 0, ±5°, ±15°, ±30° |
| Tier | fast, detailed |

Для каждого load/pressure/camber подбирается только высота ступицы — бисекцией
по нормальной нагрузке. Коэффициенты при этом неизменны. Затем проверяется
полное декартово произведение скоростей и углов/κ. Пробные оценки при подборе
высоты не продвигают материал. Для каждой строки восстанавливается одно и то
же нулевое causal state; материал получает несколько accepted intervals.
Вывод JSON различает `cases`, `invalid_cases`, `exploratory_cases`, источник и
статус. Отсутствие measured domain не является пропуском теста: тест обязан
подтвердить `status != measured` при `source_measurements == 0`.

## Независимые физические проверки

- Общий friction budget в каждой patch, конечность сил и неотрицательные потери.
- Работа касательных сил, изменение brush elastic energy и потери согласованы.
- Нулевая μ даёт нулевые касательные силы без скрытой опоры рамы.
- Отражение camber/увода и поворот вокруг Z сохраняют локальную физику.
- Уменьшение шага, fast/detailed refinement, split/merge и полный
  start/stop/reverse прогон выполняются на `Pneumatic3dModel` без MuJoCo.
- BKS3 roundtrip и 1000-step continuation проверяются в `tyre_state.cpp`.
- Hinge brake budget и отдельные ground/slope проверки — в `brake_static_3d.cpp`.

Численные допуски фиксируются тестами и V04/V06, а не подгоняются после
неудачного запуска. Неустойчивые/невалидные строки не исключаются из отчёта.
Результат всей матрицы допустим только при `invalid_cases == 0`.

Binary BKS3 v1 описывает структуру и identity, но не содержит checksum:
произвольный bit flip, который остаётся допустимым конечным числом, нельзя
обнаружить самим layout. Целостность файла обеспечивает внешний state-file
контейнер; decoder отвергает несоответствующие identity/размеры, NaN/Inf,
неканонические неактивные slots и неверные patch links. Это различие сохраняется
в отрицательных проверках, вместо обещания обнаружить любую порчу.
