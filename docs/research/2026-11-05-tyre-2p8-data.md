# Шины 2.8": проверка (2026-11-05)

**Вопрос.** Есть ли измерения горных шин 27.5×2.8 и 29×2.8 при 0,8–1,4 бар (радиальная жёсткость в зависимости от
давления, длина пятна контакта, сопротивление качению, потери при сжатии), а если нет, как честно пересчитать
параметры из откалиброванных шин 2.4"?

**Вывод.** Для **27.5×2.8** измерения есть, причём в тех же двух статьях, по которым откалиброваны шины 2.4"
([1], [2]): статическая радиальная жёсткость 60,4 Н/мм при 1,38 бар; длина пятна 117 мм при 1,38 бар и 141 мм при
0,69 бар (нагрузка 418 Н); жёсткость и затухание при ударе на 0,69–1,72 бар. **Сопротивление качению** для шин 2.8"
**не найдено** ни в одном источнике. Для **29×2.8 не найдено ничего**. Её параметры можно получить только пересчётом:
интерполяцией между измеренными 27.5×2.8 и 29×3.0 из той же статьи [1].

**Что это значит для модели.** Касается записи 4 «Решено — не сделано» и записи 21 в `simulation-decisions.md`.
Предлагается:

- заднюю шину 27.5×2.8 подогнать по измерениям тем же способом, каким подгоняли шины 2.4";
- переднюю 29×2.8 пересчитать с пометкой «пересчёт, не измерение»;
- сопротивление качению оставить пересчётом, его проверить нечем.

Ничего не включено. Отдельное наблюдение: профиль по умолчанию сейчас вообще не читает `TyreSpecs` (см. «Разбор»,
п. 6).

### 2. Что найдено (шаг 2)

**Радиальная жёсткость от давления.**

- *27.5×2.8* (найдено):
  - статика: 60,4 Н/мм при 1,38 бар, обод 35–38 мм, одна точка давления [1, рис. 8b];
  - при ударе и при колебаниях: 0,69–1,72 бар [2, табл. 2–3, рис. 9].

  | Давление | При ударе, кН/м | При колебаниях, кН/м |
  |---|---:|---:|
  | 0,69 бар | ≈43 | ≈48 |
  | 1,03 бар | ≈61 | ≈64 |
  | 1,38 бар | 78,8 | 69,0 |
  | 1,72 бар | ≈92 | ≈81 |

  Значения при 0,69, 1,03 и 1,72 бар сняты с графика.

  Статическую жёсткость при других давлениях можно вывести: поделить динамическую на её отношение к статике при
  1,38 бар (1,30 при ударе, 1,14 при колебаниях). Получается 33–42 Н/мм при 0,69 бар и 47–56 Н/мм при 1,03 бар.
  Это вывод в предположении, что отношение не зависит от давления, а не измерение.
- *Наклон по давлению*: 24–32 Н/мм на бар, почти не зависит от ширины шины [3]. Совпадает с законом шин 2.4"
  `k ≈ 22 + 24·p` Н/мм (`tyre-calibration.md` §11.2).
- *29×2.8*: не найдено. Ближайшая измеренная шина — 29×3.0 той же модели [1]: 60,4 Н/мм при 1,38 бар.

**Длина пятна контакта.**

- *27.5×2.8* (найдено): при 418 Н длина 141 мм при 0,69 бар и 117 мм при 1,38 бар; ширина 57 и 39 мм [1, рис. 5 и 16].
- *29×2.8*: не найдено. У 29×3.0 длина ≈152 мм и 127 мм при тех же давлениях [1].

**Сопротивление качению.** Не найдено ни для 27.5×2.8, ни для 29×2.8:

- в каталоге Schwalbe этих данных нет [4];
- лаборатория [5] шины 2.8" не испытывала;
- рецензируемых работ по шинам 2.8" поиск не дал;
- есть только заезды на местности из журнала [7], это подсказка, а не вывод.

**Потери при сжатии.** Для *27.5×2.8* найдено, но на шине, которая не катится [2]. Доля затухания:

| Давление | При ударе | При колебаниях |
|---|---:|---:|
| 0,69 бар | ≈3,0 % | ≈5,4 % |
| 1,38 бар | 2,4 % | 3,4 % |

Для сравнения, у 29×2.3 при 1,72 бар — 2,7 % и 4,7 %. Широкая шина затухает слабее. Для *29×2.8* не найдено.

**Геометрия.**

- *27.5×2.8* (измерено [1, рис. 4], обод 35 мм, 1,38 бар): радиус 360 мм, ширина 65,7 мм.
- *29×2.8*: не найдено. У Schwalbe такого размера нет [4].

**Что говорит исследование 2026-10-13.** Оно этих чисел не выписало. Статьи [1] и [2] в нём есть, но их
использовали для боковых сил [6]. Утверждение плана «исследование 2026-10-13 таких данных не нашло» верно для боковых
наборов, но не для радиальных данных 27.5×2.8: они лежат в тех же файлах.

### 3. Предлагаемые значения и как они получены (шаг 3)

Пометки:

- «измерение» — число взято из источника;
- «подгонка к измерению» — число подобрано так, чтобы модель повторила измерение;
- «пересчёт, не измерение» — число получено расчётом или интерполяцией;
- «оценка, как у 2.4"» — оставлено значение 2.4", измерения нет.

Подгонку `c_A`, `k_c`, `c_L` я прикинул вне репозитория. Это запись закона упругой силы из
`tyre-calibration.md` §3.1: ровная дорога, статика, 1024 луча, нагрузка 418 Н, жёсткость — сила, делённая на
прогиб. Проверка способа: для задней шины 2.4" с её коэффициентами он даёт длину пятна 132,9 мм при 1,38 бар и
122,1 мм при 1,72 бар, а цели подгонки 2.4" — 133 и 122 мм. Эти числа предварительные. Окончательные значения
должна дать штатная подгонка из плана перехода.

Как получено каждое значение.

1. **Геометрия 29×2.8.** Высота шины над посадочной полкой обода у трёх шин одной модели [1] растёт с шириной:
   2.3" — 56,5 мм (367,5 − 311), 2.8" — 68 мм (360 − 292), 3.0" — 76 мм (387 − 311). Для 29×2.8 взята та же высота,
   что у 27.5×2.8: `R = 311 + 68 = 379 мм`. Ширина каркаса та же, что у 27.5×2.8, потому что номинальная ширина и
   обод те же. Предполётная проверка 2026-10-03 брала 382 мм, разница 3 мм.
2. **`c_A`, `k_c`, `c_L` для 27.5×2.8.** Цели те же три, что для 2.4" (`tyre-calibration.md` §3.1), но из измерений
   этой шины:
   - жёсткость 60,4 Н/мм при 1,38 бар;
   - длина пятна 117 мм при 1,38 бар и 141 мм при 0,69 бар (418 Н);
   - воздух несёт 70–100 % нагрузки при рабочем давлении.

   `c_A` и `k_c` умножены на один множитель 1,141, так что их соотношение осталось как у задней 2.4". Получается
   60,4 Н/мм, а также 115,8 мм и 142,5 мм (цели 117 и 141 мм, отклонения −1 % и +1 %). Жёсткость при 0,69 бар
   выходит 39,3 Н/мм; выведенная из [2] — 33–42 Н/мм. Воздух несёт 78 % нагрузки при 1,38 бар и 70 % при 1,0 бар.
   При 0,8 бар доля падает до 63 %, ниже полосы 2.4". Для мягкой шины это ожидаемо, но полоса задана только для
   рабочего давления. Закон модели по давлению выходит примерно `k ≈ 18 + 31·p` Н/мм, наклон внутри 24–32 Н/мм на
   бар из [3].
3. **Если просто взять коэффициенты 2.4" с геометрией 2.8"**, все три цели проходят допуск ±15 %, но с перекосом:
   - жёсткость 53,4 Н/мм против 60,4 (−12 %);
   - пятно 131 мм против 117 (+12 %) и 161 мм против 141 (+14 %).

   Поэтому предлагается подгонка, а не перенос.
4. **`c_A`, `k_c`, `c_L` для 29×2.8** (пересчёт, не измерение). Цели взяты интерполяцией по радиусу между двумя
   измеренными шинами одной модели [1]: 27.5×2.8 (R = 360 мм) и 29×3.0 (R = 387 мм).
   - Жёсткость при 1,38 бар у обеих 60,4 Н/мм, цель — 60,4 Н/мм.
   - Длина пятна при 1,38 бар: 117 + (127 − 117)·19/27 ≈ 124 мм. При 0,69 бар: ≈149 мм.

   Подгонка даёт 60,4 Н/мм, 122 мм и 151 мм.
   **Насколько можно доверять такому пересчёту.** Я перенёс подгонку 27.5×2.8 на геометрию 29×3.0 только через
   радиус и ширину и сравнил с измерением 29×3.0. Жёсткость вышла 66,2 Н/мм против 60,4 (+10 %), пятно 115 мм против
   127 (−10 %). Значит, у пересчёта ошибка порядка 10 %. Интерполяция между двумя измеренными шинами должна ошибаться
   меньше, но проверить это нечем.
5. **`rate_stiffening`.** Отношение динамической жёсткости к статической у 27.5×2.8: 78,8/60,4 = 1,30 при ударе и
   69,0/60,4 = 1,14 при колебаниях [1, 2]. Середина полосы 1,22 даёт `k_r` = 0,22. У шин 2.4" было 1,16–1,35 и
   `k_r` ≈ 0,25. Для 29×2.8 взято то же значение.
6. **`loss_factor` (потери при сжатии).** Цель — доля затухания при сбросе груза 2,4–3,4 % при 1,38 бар [2]. У шин
   2.4" целью была полоса 2–5,5 %, а `η` ≈ 0,069 давал ≈3,75 %, из них ≈1 % добавляет ветвь `k_r`
   (`tyre-calibration.md` §3.1). Если считать долю затухания пропорциональной `η`, получается `η` ≈ 0,045–0,06.
   Точное значение нужно подогнать тем же опытом со сбросом 44 кг, что и для 2.4". Источник [2] мерил шину, которая
   не катится; так же откалиброваны и шины 2.4".
7. **Сопротивление качению** (пересчёт, не измерение; проверить нечем). В модели оно складывается из двух частей:
   - гистерезис каркаса. Он считается сам из формы пятна и `η`, его пересчитывать не нужно;
   - добавка протектора `tread_loss_crr`.

   Предлагается оставить добавку протектора как у шины 2.4" той же серии (резина та же). Задняя Hans Dampf: 0,00481.
   Передняя Magic Mary: 0,00586. Её зависимость от давления `(p/1,5)^-0,3` сохраняется (`model.cpp:164-171`).
   Итоговое сопротивление 2.8" при том же давлении выйдет немного ниже, чем у 2.4", потому что `η` меньше и прогиб
   меньше. При пониженном давлении оно выйдет выше. Подтвердить или опровергнуть это нечем.

   Другой вариант: держать полное сопротивление при 1,5 бар равным шинам 2.4" (0,0103 и 0,011). Он тоже не опирается
   на измерение. Выбор за пользователем.

### 4. Почему проверка 2026-10-03 отвергла материал и чем пересчёт отличается (шаг 3)

**Что проверяли 2026-10-03** (`docs/superpowers/audits/2026-10-03-plus-tire-preflight.md`):

- другую модель шины — распределённую, с пружинами по изломам (`DistributedWheelMaterial`, `HingeDensity`,
  `physical_config.hpp:53-71`), а не лучевую `TyreSpecs`;
- на условной таблице: 350 Н на 5 мм, 700 Н на 10 мм и так далее, линейно 70 кН/м. Сам аудит называет эту таблицу
  условной, это не измерение;
- с допуском 5 %.

Эта модель на малых прогибах даёт силу, растущую как прогиб в степени 3/2. Линейную таблицу она повторить не может,
отсюда ошибка 42,7 %.

**Чем отличается предлагаемое.**

1. Используется лучевая модель, по которой уже подогнаны шины 2.4". В её силе от давления есть ширина пятна `w(δ)`
   и воздух, поэтому закон по давлению получается правильной формы. Подгонка 27.5×2.8 сходится с отклонением около
   1 %.
2. Цели взяты из измерений шины 2.8" [1, 2], а не из условной таблицы.
3. Допуск тот же, что принят для 2.4": ±15 %. Допуск 5 % был задан для другой задачи.
4. Каждое число без измерения помечено «пересчёт, не измерение».

### 5. Что переход затронет кроме шины

Это для отдельного плана, здесь ничего не меняется.

- Радиус колёс меняется: перед +7 мм (372 → 379), зад +8 мм (352 → 360). От радиуса зависят геометрия велосипеда и
  передаточные отношения.
- Шина 2.8" требует обода 35–38 мм [1].
- Масса шины близка к 2.4": 1,08 кг [2]; Schwalbe Super Trail 27.5×2.80 весит 1145–1205 г [4]. Запас устойчивости
  явного счёта (ω·dt ≤ 0,4) надо пересчитать: `k_c` и `c_A` растут на 14 %, ход до удара в обод растёт с 46 до 54 мм
  (60 − 6).
- Давление ниже 0,8 бар модель обрезает до 0,8 бар (`model.hpp:51`). Значит, точку 0,69 бар из [1] можно
  использовать только как цель подгонки вне модели, задать её в поездке нельзя.

### 6. Наблюдение: профиль по умолчанию не использует `TyreSpecs`

Профиль `viewer_physics_welded.toml`, по умолчанию для `bike-ride` и проверочных поездок, задаёт
`backend = "compliant_2d"` (строки 16–17). Этот путь читает условный материал: жёсткость 130 кН/м, вязкое демпфирование
800 Н·с/м, пометка «synthetic» (`physical_config.hpp:37-40`). Шины Schwalbe 2.4" из `TyreSpecs` работают только в
профиле `viewer_physics_pneumatic.toml`.

Запись 21 в `simulation-decisions.md` («Шины сейчас Schwalbe 2.4"») верна только для этого профиля. Измерения [1, 2]
для `compliant_2d` дали бы около 60 кН/м в статике, 69–79 кН/м в динамике и 89–117 Н·с/м. Решать, менять ли это и
как это согласуется с запретом 39 (у шины нет вязкого демпфирования), должен пользователь.
