## Bounded late-failure control

Only the test header defines the friend `bike::testing::PneumaticWriterAccess`.
It reads existing tyre state/config/clock and exposes one deliberately narrow
rear-wheel failure control. It replaces the rear live **and backup** carcass
states with fully allocated `n+1` objects; their ring retains `n` rays.
`PneumaticTyreModel::assign` therefore copies matching allocated state extents.
`evaluate_carcass_into` checks state count against ring count before indexing
any ray or scratch output, and throws after front-wheel evaluation. This
exercises the same late two-wheel rollback boundary without creating an
out-of-bounds object. After restoring complete `n` states, the valid retry is
compared with a fresh identical rig, including force and serialized state.

## Required captures

`tests/reference/test_pneumatic_tire_forces.py` now has explicit opt-in
capture calls only in `test_oracle_parity_with_xfrc_writer`. The original
assertions remain. Patch iteration is sorted for stable capture order.

For **each** of the two node IDs ending in `[fast]` and `[detailed]`, on
**darwin-arm64 and linux-aarch64**, capture four steps. Each step records,
front then rear:

1. The three legacy carcass rows: `delta_prev_m`, `elastic_prev_n`,
   `maxwell_force_n` (`<f8`, `[n_rays]`).
2. `initialized` as a binary64 scalar (`shape=[]`).
3. Sorted patch keys as `<i8`, `[patch_count,2]`, including empty `[0,2]`.
4. Each sorted patch's scalar `kappa_prime` and, on detailed patches, its
   binary64 bristle row.
5. Scalar output-patch count and each output patch's 3D force and scalar
   signed slip.
6. After both wheels, the complete generalized-force vector.

Native readers use exact labels, explicit shapes, raw bits and `done()`.
Actual entry counts depend on captured contact topology; they must be taken
from the real sidecars after capture, not guessed from this source review.
The native legacy xfrc writer is also exercised as a valid-input cross-check;
it is never used to generate replacement Python expected values.
