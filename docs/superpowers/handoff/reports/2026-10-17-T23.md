`BIKE_NATIVE_BUILD_PATH`, `NATIVE_TEST_BUILD_PATH`, supported extension
suffixes, exact-one-artifact selection and `load_native_extension`'s public
signature are preserved. Fresh and cached application loads now verify the
compiled source stamp. Missing markers fail source-native mode without
searching cwd for an unrelated checkout. A pure wheel remains Python-only;
there is no implicit compilation, artifact retry/unload or Python fallback.

The original `ImportError`/`OSError` or runtime-identity failure remains the
exception cause. Diagnostics identify the selected build/artifact, actual
Python/SOABI and platform, and show explicitly invoked doctor/configure/build
commands. Missing/stale/cached-conflict cases remain hard failures.

Dev wrappers consistently propagate the selected absolute uv environment and
reject a CMake cache belonging to another source/build/venv. Interpreter
comparison retains venv identity even when different venvs point at the same
base Python binary. Bootstrap stays `uv sync --locked`; it was not weakened
to bypass lock validation.

Doctor replaces the compiling dependency CLI with a fresh runtime-only probe.
It checks source/artifact identity, engine image agreement, private symbols,
numerical-provider evidence and recorded installation paths. It fails before
native import when interpreter/artifact/context preflight fails. It consumes
the existing sanitizer policy and reinjects the selected runtime for a direct
Python child on Darwin/Linux. Configure remains the owner of full numerical
ABI compile/link qualification.

## Context compatibility and review

Schema 2 and its prior fields remain intact. All inspected runtime/test context
consumers tolerate the new top-level diagnostic fields. Older contexts remain
usable by those existing readers; the new doctor requests reconfiguration to
obtain missing install identity. `native_loader.py` changes are additive for
T21/T22. The runtime owner co-reviewed the application loader and source
identity change.

The CMake edit changes the native source fingerprint. The selected extension
must be **explicitly reconfigured and rebuilt before later native execution**;
this was not done here. Relocated sources require a fresh local build; copied
caches and venvs are not made portable by search paths.

Independent review found two gaps in the initial implementation: a doctor
child could lose the selected macOS sanitizer preload, and the no-compilation
control initially covered only the no-build branch. Both were corrected;
Darwin/Linux preload controls and both doctor branches are now authored.
The runtime-identity failure path also preserves its cause. Final static
review reported no remaining material findings.
