## 7. Rollback

Rollback is ordinary reviewed commit reversal of the problematic
portability change while retaining user work and original macOS operation;
user build/source directories are never deleted and the repository is never
force-reset. An incomplete Linux qualification means Linux support remains
unreleased — macOS is not removed to simplify the matrix.
