## Общие ограничения

- **Язык.** Язык файла — русский, простой, без англицизмов и жаргона. Вместо «голден» пиши «эталонная запись»,
  вместо «гейт» — «проверка», вместо «фрихаб» — «втулка свободного хода», вместо «дефолт» — «по умолчанию».
  Имена файлов, ключей, профилей и трасс пишутся в `обратных кавычках`, как в коде.
- **Числа.** В текст попадают только числа, которые выбрал пользователь. Для остальных значений даётся ссылка
  на файл.
- **Источники.** У каждой записи есть дата и источник: коммит, `файл:строка` или сессия (первые 8 символов
  имени файла разговора).
- **Отменённые решения.** Отменённое решение не записывается отдельно. Оно упоминается внутри нового: «было
  30 зубьев».
- **Раздел AGENTS.md** «Ограничения модели райдера и мотора» в этом плане не меняется. Подраздел «Передача» (КПД
  100 %) пользователь велел записать 2026-11-05; он уже добавлен вне плана.
- **Чужие правки.** Незакоммиченное удаление строки «Canonical source: …» в AGENTS.md сделал пользователь. Его не
  трогать и не коммитить вместе со своими правками без вопроса.
- **Коммит** — только по просьбе пользователя.
- **Бюджет тестов: 0 минут.** Меняются только `docs/agents/simulation-decisions.md` и одна строка AGENTS.md. Это не
  C++, не CMake и не `tools/*.sh`, поэтому уровни проверки 1 и 2 из AGENTS.md ничего не доказывают.
