# Оцифровка Sadauckas & Dressel 2020 — боковые характеристики MTB-шин

**Статус:** `digitised`, два независимых прохода. **Гейт WP-V3:** пройден —
расхождение проходов на целевой серии ≤ 2.5 % (порог 10 %).

Спор D1 мастер-плана: аудит и внешний отчёт Gemini извлекли из одной и той же
статьи несовместимые полосы боковых коэффициентов. Здесь — собственная
пиксельная оцифровка и вердикт, кому верить.

**Термины.** *Cornering stiffness* `C_α` — наклон кривой боковой силы `F_y`
по углу увода `α` в начале координат; в статье он нормирован на вертикальную
нагрузку (`C_α/F_z`, единицы 1/rad) и получен как произведение коэффициентов
`B·C·D` мотоциклетной Magic Formula, фитованной к сырым свипам. *Camber
stiffness* `C_γ` — то же по углу развала `γ` (наклон колеса). *Длина
релаксации* `σ_y` — пробег, на котором `F_y` выходит на режим после ступеньки
угла; `σ_x` — продольный аналог. `F_z` — вертикальная нагрузка, `p` —
давление.

**Источник:** Dressel A., Sadauckas J. «Characterization and Modelling of
Various Sized Mountain Bike Tires and the Effects of Tire Tread Knobs and
Inflation Pressure», *Appl. Sci.* 10(9):3156, 2020, DOI
10.3390/app10093156. Стенд — беговая дорожка UWM, нагрузка
**F_z = 418 Н — единственная** во всех боковых измерениях статьи, скольжение
±2°, развал +15/−25°, поверхность — non-skid лента (не асфальт, не камни).

## 2. Методика и два независимых прохода

Ось X обеих панелей — давление 0–60 psi; Y панели a — 0–25 1/rad, панели b —
0–3.0 1/rad (прочитано по тик-лейблам). Легенда: цвет = семейство шины,
маркер = вариант конструкции (залитый = knobby/file-tread, открытый = bald);
полное соответствие в `notes.md`.

| | Проход A | Проход B |
|---|---|---|
| Растр | изображение, встроенное в PDF (1725×1022) | издательский полный растер `g017.png` (3457×3399) |
| Калибровка осей | МНК по центрам OCR-верифицированных блоков тик-лейблов | края рамки графика → заявленные пределы осей |
| Извлечение точек | медиана y пикселей маски в каждом столбце | среднее y по столбцу, связные компоненты |

Серии одного цвета (knobby vs bald у 2.3″/2.5″) разделяются связными
компонентами — по значению они разнесены без пересечений.

**Контроль на авторских числах.** На Fig. 3a/3b напечатаны сами коэффициенты
фита авторов: `BCDs = 10.488`, `BCDc = 0.909` 1/rad (29×2.3″ knobby,
25 psi). Наша оцифровка Fig. 17 даёт 10.68 и 0.89 — то есть **трубопровод
воспроизводит напечатанные авторами значения с точностью 2–3 %**, а прямая
оценка наклона сглаженной кривой Fig. 3a при |α| ≤ 0.5° даёт 10.5 1/rad.

**Расхождение проходов** (полный список в `points/final_*.csv`): на целевой
серии 29×2.3″ knobby 25 mm — **0.3–2.5 %** по всему диапазону давлений.
Известные артефакты на второстепенных сериях (29×3.0″ @15 psi, bald-2.5″
camber @15 psi — задевание соседних маркеров) помечены в `notes.md` и на
итог не влияют.

## 4. Показатели зависимости

**Давление `n_p`** (log-лог наклон по точкам проход-mean; «n_p» — показатель
в `C ∝ p^{n_p}`):

| серия | диапазон | n_p |
|---|---|---|
| C_α/F_z knobby 25 mm | 10–50 psi | **−0.20** |
| C_α/F_z knobby 25 mm | 20–50 psi | −0.26 |
| C_γ/F_z knobby 25 mm | 10–50 psi | **−0.53** |
| C_γ/F_z knobby 25 mm | 20–50 psi | −0.47 |

Раздвоение подтверждено: `n_p(C_γ) ≈ −0.5` при `n_p(C_α) ≈ −0.2`. Механизм в
статье — сокращение числа кнобов в пятне при росте давления
(модель «кнобы ∥ + каркас ÷» воспроизводит измеренную `K_y(p)` в пределах
8–15 %).

**Нагрузка `n_F`: в статье измерить невозможно** — все боковые измерения при
одной `F_z = 418 Н`. Аудит взял −0.55 из фитов Dell'Orto (Zenodo); Gemini —
q_Fz ≈ 0.85 по абсолютной жёсткости, т.е. ≈ −0.15 в нормированной. Мой
независимый пересчёт из напечатанных таблиц Dell'Orto 2024 VSD
(Tables 2–6, camber 0°, `points/dellorto_nF_check.json`):

`n_F` нормированного `C_α/F_z` по 6 шинам и 11 парам нагрузок:
**медиана −0.38, полоса −0.55…−0.13** (один аномальный +0.19 у T04@500 кПа —
стендовая странность, помечена авторами). Аудит и Gemini взяли противоположные
края этого разброса: −0.55 ≈ T03/T05 @300 кПа, −0.15 ≈ T01/T02.
Честное значение — **полоса −0.15…−0.55**, точка −0.35.

## 5. Релаксация σ_y/σ_x — в статье её нет

Полнотекстовая проверка: слов «relaxation», «transient response», «σ» в смысле
длины релаксации в Dressel & Sadauckas 2020 **нет** — статья стационарная
(slip/camber свипы + статические жёсткости). Число σ_y/σ_x ни аудита, ни
Gemini из этой статьи не следует.

Что можно вывести из статьи (как сделал аудит): `σ_y = C_α/K_y` — длина
релаксации как отношение наклона силы к статической боковой жёсткости
(пружинная модель одной клетки). С напечатанными BCDs = 10.488 и
K_y = 27 710 Н/м:

```
σ_y = 10.488 · 418 Н / 27 710 Н/м = 0.158 м   (@25 psi, 418 Н)
σ_y/σ_x = 0.158 / 0.060 = 2.6               (если σ_x = 60 мм, authored)
```

Оговорки: статическая `K_y` UWM включает податливость колеса/спиц → истинная
шинная `σ_y` ниже (оценка аудита +0/−30 % → σ_y 0.11–0.16 м). Независимое
подтверждение порядка: Dell'Orto 2023 (Meccanica) измерил σ_y = 78–199 мм для
гоночных шин при 3.5–7.5 бар — у мягкой MTB-шины при 1–2 бар σ_y должна быть
больше, т.е. 0.15–0.19 м правдоподобно, а σ_y/σ_x = 1.35 (Gemini, из
«полудлины пятна + сдвиг») выглядит заниженным: 0.08 м < минимума гоночных
измерений.

## 6. Кросс-чек с городскими шинами Dell'Orto

Из напечатанных таблиц VSD-2024 (camber 0°, пересчёт в 1/rad):
T01 Balloon 11.5–11.9 @4 бар; T02 Brooklyn 15.3–17.3 @3–4 бар;
T03 Energizer 13.1–17.6 @3–5 бар; T05 Scalato 17.6–22.0 @3–4 бар;
T06 Super Moto-X 62-584 (2.4″, ближайший по ширине слик): 12.8–14.4 @3.4 бар
(из датасета Zenodo 7866646, по аудиту C). Knobby MTB при 3.45 бар = 9.37.

Отношение «городской слик / MTB knobby» при ~3.4 бар: **≈1.4** для T06,
до ~2 для тяжёлых каркасов T05. Аудитная «≈1.2» — оптимистичный нижний край,
но внутри гейта 0.5–2.0: полоса MTB не противоречит городским данным.

## 7. Разбор расхождения аудит ↔ Gemini

| Величина | Аудит | Gemini | Оцифровка (WP-V3) | Вердикт |
|---|---|---|---|---|
| C_α/F_z knobby 2.3″, 1–2 бар | 9.5–13 | 5.8–8.6 | **10.6–12.7** (весь диапазон 0.7–3.4 бар: 9.4–12.7) | аудит подтверждён; Gemini ~×0.65 ниже |
| C_γ/F_z knobby 2.3″ | 0.9–1.5 | 0.55–0.99 | **0.67–1.55** на 0.7–3.4 бар; на 1.38–1.72 бар: 0.89–1.06 | оба правы в своих давленных окнах; номинал Gemini (0.78 @1.5 бар) занижен |
| σ_y/σ_x | 2.5 | 1.35 | в статье нет; вывод по C_α/K_y → ~2.6 | статус `derived/unpinned`; аудит ближе |
| n_p (C_α) | −0.2 | −0.22 | **−0.20…−0.26** | совпадают, подтверждено |
| n_p (C_γ) | −0.5 | −0.32 | **−0.47…−0.53** | аудит подтверждён |
| n_F | −0.55 | −0.15 | по Dell'Orto: −0.15…−0.55 | оба — края реального разброса |

**Наиболее вероятная причина занижения Gemini по C_α (фактор ~0.65):**
их же «slick-полоса 8.5–11.5» ≈ наша оцифрованная *knobby*-кривая
(9.4–12.6). Похоже, кривая knobby была принята за «слик», после чего
применён дополнительный дисконт податливости кнобов ~×0.65 (≈ отношению
knobby/bald 12.5/20.8 ≈ 0.6) — двойной учёт эффекта, который в данных уже
содержится. Версии «градусы vs радианы» и «другая нормировка нагрузки» не
проходят проверку масштаба (дали бы ×57 или точно ×2). Прямое опровержение:
напечатанный авторами `BCDs = 10.488` при 25 psi — не 5.8–8.6.

**По C_γ:** реальная причина — разные давленные окна цитирования (аудит
описывал 0.7–1.7 бар, Gemini — «выше 1.4 бар»), кривая при этом круто
падает (n_p ≈ −0.5), отсюда непересекающиеся полосы при совместимых данных.

**По σ_y/σ_x:** оба числа — выводные, не из статьи; спор про методы оценки
(статическая K_y vs полудлина пятна), не про оцифровку.

## 8. Рекомендация для `tyre_lateral_reference.json` (вход WP-P1)

```json
{
  "C_alpha_per_load_per_rad": { "band": [10.5, 12.7],
    "conditions": "knobby 2.3-2.4in class, p=1.0-1.7 bar, Fz=418 N",
    "status": "digitised" },
  "C_gamma_per_load_per_rad": { "band": [0.85, 1.3],
    "conditions": "same, p=1.0-1.72 bar",
    "status": "digitised" },
  "pressure_exponent_C_alpha": { "value": -0.2, "band": [-0.26, -0.15],
    "status": "digitised" },
  "pressure_exponent_C_gamma": { "value": -0.5, "band": [-0.6, -0.45],
    "status": "digitised" },
  "load_exponent": { "band": [-0.55, -0.15], "nominal": -0.35,
    "status": "cross_reference_dellorto" },
  "sigma_y_m": { "band": [0.11, 0.19], "nominal": 0.16,
    "status": "derived (sigma_y=C_alpha/K_y), unpinned" },
  "sigma_y_over_sigma_x": { "band": [1.8, 3.2], "nominal": 2.6,
    "status": "derived; NOT in the paper" }
}
```

**Пинить:** `C_α/F_z`, `C_γ/F_z` в проектной полосе 1.0–2.0 бар и
`F_z ≈ 418 Н`, оба `n_p` раздельно. **Оставить authored/unpinned:** `n_F`
(в статье одна нагрузка; экстраполяция за 530 Н всегда authored),
`σ_y/σ_x` и абсолютный `σ_y` (выводные, метод C_α/K_y завышен
колесом), любые значения вне ширины 2.3–3.0″. Для шин >2.4″
(проектная Magic Mary 2.35 — на границе) брать интерполяцию по ширине:
C_α/F_z растёт до ~14 у 2.8–3.0″, C_γ/F_z до ~1.2–1.5 — ширина
учитывается параметром, не расширением полосы.

Ограничения измерения: одна нагрузка 418 Н; свип увода узкий (±2°) — BCD
это наклон MF-фита, сырой наклон за ±2° ниже (~9.5–10 из-за кривизны);
поверхность — лента, не камень; `F_y ≤ F_z·tan γ` — не физический потолок
(широкие knobby и слики превышают его), только модельный клип.
