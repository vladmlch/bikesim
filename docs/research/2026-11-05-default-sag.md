# Просадка подвески по умолчанию: проверка (2026-11-05)

**Вопрос.** Даёт ли настройка подвески по умолчанию (вилка 85,2 psi и 2 токена, пружина амортизатора 114 600 Н/м)
просадку 30 % спереди и 30 % сзади под райдером 80 кг, как решил пользователь 2026-10-03?

**Вывод.** Нет, не даёт: спереди просадка больше 30 %, сзади меньше.
- **Вилка:** 60,6 мм из 180 мм, то есть **33,7 %**. Для 30 % нужно 54 мм.
- **Заднее колесо:** 45,9 мм из 180 мм, то есть **25,5 %**. Для 30 % нужно 54 мм.
- **Шток амортизатора:** 14,5 мм из 65 мм, то есть 22,3 %.

Эти числа взяты из записанных состояний покоя. Каждое такое состояние программа проверяет на совпадение с
текущей моделью при загрузке. Расчёт по формулам пружин даёт те же числа. Новый прогон для ответа не нужен.
Его можно сделать для подтверждения, команда ниже.

**Что это значит для модели.** Это пункт 9 раздела «Решено — не сделано» и пункт 25 раздела «Действует» в
`docs/agents/simulation-decisions.md`. Выбрать один из двух путей должен пользователь:
1. **Поменять значения по умолчанию.** По расчёту нужно примерно **95 psi** в вилке (вместо 85,2 psi) и примерно
   **95 000 Н/м** у пружины амортизатора (вместо 114 600 Н/м). Это оценка. Точные числа подберёт ключ `--sag 30`,
   после этого их можно записать как значения по умолчанию.
2. **Всегда задавать `--sag 30`** у `bike-ride`.

## Разбор

### Шаг 1. Как считается просадка

- **Определение.** Просадка — это ход подвески в покое под райдером, делённый на полный ход:
  - спереди — ход вилки, делённый на 180 мм;
  - сзади — **ход заднего колеса**, делённый на 180 мм, а не ход штока (источники 3, 4).
- **Откуда берётся ход.** Его не считают по формуле. Программа ставит велосипед с райдером на дорогу в полной
  модели и гасит движение, пока всё не замрёт (источники 5, 6).
- **Почему нельзя посчитать только из параметров.** Сила на каждую пружину зависит от того, как вес делится между
  колёсами. Это деление задаёт поза сидящего райдера, а она находится только в полной модели.
  - В коде есть упрощённый расчёт `compute_suspension_tuning_for_sag`
    (`native/src/model/suspension_setup.cpp:1060-1172`). Он ставит вместо райдера одну массу и даёт другое деление
    веса: 46,7 % на переднее колесо, около 478 Н.
  - В полной модели на переднюю шину приходится 431 Н, то есть 42,1 %.
  - Поэтому его ответ (118,5 psi и 93 984 Н/м в `tests/fixtures/model/tuning.json`) к сидящему райдеру не подходит.
- **Записанные состояния покоя.** Готовые результаты полной модели уже есть (источники 8, 9).
  - Это состояния с настройкой по умолчанию и райдером 80 кг.
  - Они привязаны к текущей модели отпечатком (источник 10). Загрузку проверяет тест
    `native/tests/initialization/test_pipeline.cpp:124-131`, он идёт в обычном наборе тестов.
  - Последняя полная проверка `native` прошла на `5461865e`. С тех пор в `native/`, `tests/` и `examples/` ничего не
    менялось (`git diff 5461865e..HEAD`).
  - Значит, для ответа хватает этих состояний и формул пружин.

### Шаг 2. Формулы и числа (райдер 80 кг, вся система 104,4 кг, профиль `viewer_physics_welded`)

**Вилка.**
- Площадь поршня A = π·(0,012 м)² = 4,524·10⁻⁴ м².
- Объём положительной камеры V₊ = A·0,280 м − 2·8 см³ = 110,7 см³. Объём отрицательной камеры V₋ = A·0,055 м = 24,9 см³.
- Абсолютное давление p₀ = 85,2 psi·6894,76 Па/psi + 101 325 Па = 688 758 Па.
- Сила F(x) = A·(p₀·(V₊/(V₊ − A·x))^1,4 − p₀·(V₋/(V₋ + A·x))^1,4) (источник 7).
- При x = 60,62 мм F = 354,1 Н вдоль вилки.
- Проверка нагрузкой:
  - на переднюю шину приходится 431,1 Н;
  - без веса нижней части вилки и колеса (1,5 кг + 2,4 кг = 38,3 Н) остаётся 392,8 Н;
  - вдоль вилки при угле 64° это 392,8 Н × sin 64° = 353,1 Н.
  - Расхождение с 354,1 Н — 1 Н, то есть 0,3 %.
- Итог: просадка спереди = 60,62 мм / 180 мм = **33,7 %**.
- Давление для 54 мм при той же силе — **95,1 psi**. При 90 psi вилка сядет на 57,3 мм, при 100 psi — на 51,1 мм.

**Амортизатор.**
- Сила пружины: 114 600 Н/м × 0,014466 м = 1657,9 Н.
- Отношение хода колеса к ходу штока в этой точке по таблице (источник 11) — 3,011.
- Отсюда сила на колесо, которую держит пружина: 1657,9 Н / 3,011 = 550,6 Н. Это нагрузка на заднюю шину 593,2 Н
  без веса колеса и задних перьев.
- Итог: ход колеса 45,86 мм / 180 мм = **25,5 %**; ход штока 14,47 мм / 65 мм = 22,3 %.
- Для 54 мм хода колеса шток должен войти на 17,19 мм, отношение там 2,959. Сила пружины тогда
  550,6 Н × 2,959 = 1629 Н, жёсткость 1629 Н / 0,01719 м = **≈ 94 800 Н/м**.

**Оговорка к оценкам 95 psi и 94 800 Н/м.** При другой просадке велосипед немного наклонится, и вес между колёсами
перераспределится. Поэтому это оценка с точностью до нескольких процентов, а не точное значение. Точные числа даст
подбор по ключу `--sag 30` (источник 3).

**Другие шины.**
- С пневматической шиной просадка та же: 33,6 % спереди и 25,5 % сзади.
- С распределённой шиной 32,6–32,9 % спереди и 25,7 % сзади.
- Вывод не зависит от выбора шины.

### Что говорят производители о целевой просадке

Это справка. Решение пользователя «30 % спереди, это не обсуждается» она не отменяет.
- **FOX, вилка:** просадка 15–20 % хода; для 180 мм — 27–36 мм (источник 14).
- **FOX, амортизатор:** 25–30 % **хода штока** (источник 15).
- **RockShox, старое руководство:** 10–40 % хода вилки (источник 16).
- **RockShox, современная таблица:** давление задаётся по весу райдера, процент просадки не указан (источник 17).

**Расхождение в определении задней просадки.** Производители считают её по ходу штока, а код — по ходу заднего
колеса. У этой рамы отношение ходов падает с 3,01 до 2,96, поэтому проценты расходятся:
- сейчас: 25,5 % по колесу и 22,3 % по штоку;
- 30 % по колесу (54 мм) — это 26,4 % по штоку;
- 30 % по штоку (19,5 мм) — это 60,8 мм колеса, то есть 33,8 %; для этого нужна жёсткость ≈ 82 400 Н/м.

Какое определение имел в виду пользователь, нужно спросить его. В коде сейчас принято определение по колесу.

**Давление в модели и в реальной вилке.** Psi модели нельзя сравнивать с таблицей RockShox (источник 17). Камера
в модели упрощена: внутренний диаметр 24 мм, длины 280 и 55 мм. Её размеры не сверены с ZEB.

## Не найдено / неуверенно

- **Покой определён не однозначно** (источник 12). Другой способ поиска покоя (`equilibrium_relaxation = "kinetic"`)
  останавливается на 3,7 мм дальше или ближе по ходу вилки, это ±2,1 % хода. По умолчанию стоит `cycle`, числа выше
  получены с ним. Даже с этим разбросом спереди не 30 % (54 мм ± 0,5 мм).
- **Сзади** разброс между способами в тестах не измерен. Но 45,9 мм отстоят от 54 мм на 8 мм.
- **Записанные состояния сделаны на `14e9c054` (2026-11-04).** Позже менялось крепление седла (`d83e8d8e`). В
  сообщении коммита сказано, что в обычных поездках результат не меняется бит в бит, и отпечаток модели (источник 10)
  по-прежнему совпадает. Но отпечаток не покрывает изменения в самих формулах сил. Поэтому новый прогон полезен как
  подтверждение, хотя для ответа он не нужен.
- **`bike-ride` без `--physics-config`** берёт другую физику по умолчанию и райдера-одну массу (`lumped`,
  `native/src/cli/configuration.cpp:113,149`). Там деление веса другое, и просадка будет другой. Числа выше относятся к
  профилю `viewer_physics_welded`, который комментарий в нём называет профилем по умолчанию для `bike-ride`.
- **Документы производителей:** у FOX и RockShox не найдено рекомендации 30 % для вилки. Руководство RockShox
  2001–2012 прочитано только в пересказе поиска.

## Подтверждающий прогон (если нужен)

Одна команда в дереве с собранным `build/native-release`. Она ищет покой и сразу печатает ход:

```bash
build/native-release/bin/bike-settle \
  --physics-config examples/research/viewer_physics_welded.toml \
  --track flat --rider articulated_planar --rider-mass 80 \
  --out /tmp/sag-check/welded_flat_state.json
```

- **Что читать.** Строку `[bike-settle] fork <X> mm, shock <Y> mm, rear <Z> mm`. Строку `freshly settled` или
  `auto-cache hit`. Кэш привязан к тому же отпечатку модели, поэтому годится любой из двух случаев, но в отчёте нужно
  указать, какой был.
- **Подтверждает 30/30 %:** X и Z оба от 53,5 до 54,5 мм. Это допуск подбора, `sag_fit.cpp:32`.
- **Опровергает (ожидается):** X ≈ 60,6 мм (33,7 %), Y ≈ 14,5 мм, Z ≈ 45,9 мм (25,5 %).
- **Если X отличается от 60,6 мм больше чем на 4 мм:** записанные состояния устарели, и выводы надо пересчитать по
  новым числам.
- **Альтернатива — `bike-ride`.** Подойдёт и короткая поездка, если выбор пути 1 или 2 захочется проверить на ней:
  - `bike-ride --physics-config examples/research/viewer_physics_welded.toml --track flat --headless --duration 0.01 --no-plots --check-policy diagnostic`;
  - в итоговом JSON на экране читать объект `equilibrium`: поля `fork_travel_mm`, `shock_stroke_mm`, `rear_travel_mm`.
