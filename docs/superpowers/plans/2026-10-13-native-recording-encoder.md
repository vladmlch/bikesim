# Native Columnar Recording Encoder Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move run-recording table emission from the pure-Python `encode_rows`/`arrow_batch` path to a catalog-driven C++ projector, cutting `--record` finalization from ~60 s to seconds without changing the published container semantics.

**Architecture:** The Python field catalog (`recording/catalog.py::TableSpec`) stays the single source of truth. A new compiler (`recording/native_encode.py::compile_plan`) turns each `TableSpec` into a plain-data extraction plan; a new C++ projector (`native/src/runtime/encode.cpp`, bound as `OwnedNativeEpisode.encode_table`) executes it over retained `PhysicalSampleData` and returns **column pieces** — flat numpy buffers, offsets, validity masks, nested child pieces — never Arrow objects and never per-row Python dicts. `native_encode.py::pieces_to_arrow` assembles the same `pa.RecordBatch` `arrow_batch(encode_rows(...))` would produce, so publication output is bitwise-identical. Tables whose specs use not-yet-covered dtypes compile to `None` and keep flowing through the reviewed Python encoder — per-table eligibility is the staging seam. `encode_rows` remains permanently as the differential oracle and as the path for duck-typed episodes (`OwnedPythonEpisode`, test doubles).

**Tech Stack:** C++23 (native extension, nanobind), Python, pyarrow 26, DuckDB, pytest. No Arrow dependency inside `native/` — C++ emits raw buffers only.

**Spec:** `docs/RECORDING.md` (data model and type semantics section) + `docs/agents/native-engineering.md` (mandatory reading before touching `native/`). Existing design tags referenced: R01–R21 in `docs/superpowers/specs/2026-10-12-run-recording-design.md`.

## Global Constraints

- Output must be **bitwise identical** to the Python oracle path: same columns, same order, same values — including NaN payloads, `±inf`, `-0.0`, empty containers, and absent-vs-explicit-null distinctions. `dt_s` stays `end_time_s - time_s` (one IEEE subtraction, identical in both paths).
- `encode_rows`/`arrow_batch`/`decode_rows` are not deleted. They are the oracle and the only path for non-`OwnedNativeEpisode` sources.
- Every failure that is a `ValueError`/`EncodingError` subclass in Python must surface as `ValueError` from the native path (`std::invalid_argument` maps correctly through nanobind). Error *text* may differ; rejecting-vs-accepting may not.
- `NativePhysicalSource._canonical` rewrites `channels['model_status']['numerically_valid']` bool → `'true'|'false'` verdict text (`native.py:111-117`). The projector reproduces this for the `channel_model_status` field `numerically_valid` (path `('model_status','numerically_valid')`, dtype `varchar`): bool → `'true'`/`'false'`, any other value passes through verbatim. Without this the column flips type.
- Identity keys are emitted implicitly: `physics`/`channels` emit `interval_id` per row; `forces` emits `interval_id` + `component` per exploded row; `episode_id` is generated by the assembler (never read from data).
- Batch boundaries must not change output: `encode_table(plan, start, limit)` carries no cross-call state. Diff-style emissions seed from row `start - 1` when `start > 0`.
- New C++ files are added to the `bike_native` target in `native/CMakeLists.txt`; sweeps enumerate target sources, so `check_tidy`/`check_cppcheck`/`check_analyzer`/`check_odr` pick them up automatically.
- Python runs via `uv run --frozen ...` (`--group native` when the extension must load). Test builds: `cmake --build native/build --target bike_native`.
- Test profile cheat-sheet for this work: inner loop = `uv run --frozen --group native pytest tests/reference/test_native_encode_columns.py -x -q` (seconds); per-phase sweep = `cmake --build native/build --target check_tidy` and `check_cppcheck`; final gate (once, at the end) = `bash tools/run_tests.sh native`.
- RTSan: none of the new code runs inside realtime regions — recording publication happens post-run. Do not add `noexcept` speculatively; allocation-bearing boxing stays outside any hot path anyway.
- pyarrow is imported lazily inside functions (module `recording` must stay importable without it — see `storage.py::_connect`/`_write_batch` precedent).

```cpp
// ---- authored-episode constructor for encoder parity tests ----
// Accepts the canonical sample-row dict shape
// (tests/reference/_recording_support.py::sample_row). The ColumnLayout is
// zeroed on purpose: flat_columns is legacy surface the new typed export
// must not consume, so the layout indices are never read here.
Wire python_to_wire(nb::handle value, const char *path) {
    if (value.is_none()) return Wire(nullptr);
    if (nb::isinstance<nb::bool_>(value)) return Wire(nb::cast<bool>(value));
    if (nb::isinstance<nb::int_>(value)) return Wire(nb::cast<std::int64_t>(value));
    if (nb::isinstance<nb::float_>(value)) return Wire(nb::cast<double>(value));
    if (nb::isinstance<nb::str>(value)) return Wire(nb::cast<std::string>(value));
    if (nb::isinstance<nb::dict>(value)) {
        WireObject object;
        for (const auto &[k, v] : nb::borrow<nb::dict>(value))
            object.emplace_back(nb::cast<std::string>(k), python_to_wire(v, path));
        return Wire(std::move(object));
    }
    if (nb::isinstance<nb::list>(value) || nb::isinstance<nb::tuple>(value)) {
        WireArray array;
        for (const nb::handle item : nb::borrow<nb::list>(value))
            array.push_back(python_to_wire(item, path));
        return Wire(std::move(array));
    }
    // numpy scalars/arrays from fixtures
    const nb::object numpy = nb::module_::import_("numpy");
    if (nb::isinstance(value, numpy.attr("generic")))
        return python_to_wire(value.attr("item")(), path);
    if (nb::isinstance(value, numpy.attr("ndarray"))) {
        WireArray array;
        for (const nb::handle item :
             nb::borrow<nb::list>(value.attr("tolist")()))
            array.push_back(python_to_wire(item, path));
        return Wire(std::move(array));
    }
    throw std::invalid_argument(
        std::string(path) + ": unsupported authored value type");
}

PhysicalSampleData authored_sample(nb::handle row) {
    const wire::Dict dict{.value = wire::mapping(row, "sample row"),
                          .path = "sample row"};
    PhysicalSampleData sample;
    sample.interval_id = wire::integer(wire::field(dict, "interval_id"), "interval_id");
    sample.time_s = wire::real(wire::field(dict, "time_s"), "time_s");
    sample.end_time_s = wire::real(wire::field(dict, "end_time_s"), "end_time_s");
    sample.qpos = wire::vector(wire::field(dict, "qpos"), "qpos");
    sample.qvel = wire::vector(wire::field(dict, "qvel"), "qvel");
    for (const auto &[name, force] :
         wire::mapping(wire::field(dict, "forces"), "forces"))
        sample.forces.emplace_back(wire::string(name, "force component"),
            wire::vector(force, "forces member"));
    for (const auto &[name, power] :
         wire::mapping(wire::field(dict, "powers_w"), "powers_w"))
        sample.powers_w.emplace_back(wire::string(name, "power name"),
                                     Wire(wire::real(power, "power value")));
    sample.channels = object_of(python_to_wire(wire::field(dict, "channels"), "channels"));
    return sample;
}

OwnedNativeEpisode make_episode(nb::handle rows, nb::handle generation) {
    std::vector<SamplePtr> samples;
    for (const nb::handle row : wire::sequence(rows, "rows"))
        samples.push_back(std::make_shared<const PhysicalSampleData>(
            authored_sample(row)));
    const int gen = static_cast<int>(wire::integer(generation, "generation"));
    return OwnedNativeEpisode::seal(gen, samples, ColumnLayout{});
}
```

```python
"""Shared oracle plumbing for native-encoder parity tests."""
import numpy as np
import pyarrow as pa
from native_loader import load_native
from bike_sim.recording.encoding import encode_rows
from bike_sim.recording.schema import arrow_batch

bike_native = load_native()


def make_episode(rows, generation=1):
    return bike_native.runtime_make_episode(list(rows), generation)


def oracle_batch(spec, rows, episode_id=0):
    """TableBatch straight through the reviewed Python encoder."""
    return encode_rows(spec, rows, episode_id=episode_id)


def native_record_batch(spec, episode, episode_id=0, catalog=None):
    # Lazy import: this module exists in Task 1 before native_encode.py
    # lands in Task 2, and the module must not require pyarrow's siblings.
    from bike_sim.recording.native_encode import compile_plan, pieces_to_arrow
    all_roots = None if catalog is None else sorted(catalog.channel_roots())
    plan = compile_plan(spec, all_roots=all_roots)
    assert plan is not None, f'{spec.name}: no native plan (fell back?)'
    row_count, pieces = episode.encode_table(plan, 0, episode.row_count)
    return pieces_to_arrow(spec, row_count, pieces, episode_id, pa)


def oracle_record_batch(spec, rows, episode_id=0):
    return arrow_batch(spec, oracle_batch(spec, rows, episode_id),
                       episode_id, pa)


def column_bits(array):
    """Deterministic byte identity of one Arrow column.

    validity bitmap + offsets + value payload bytes, recursing into
    struct/map children — catches -0.0, NaN payloads, empty vs absent.
    """
    a = array.combine_chunks() if isinstance(array, pa.ChunkedArray) else array
    parts = []
    if a.null_count or isinstance(a, (pa.StructArray,)):
        buf = a.buffers()[0]
        parts.append(b'' if buf is None else buf.to_pylist().__bytes__())
    if isinstance(a, pa.ListArray) and not isinstance(a, pa.MapArray):
        parts.append(np.asarray(a.offsets).view(np.int32).tobytes())
        parts.append(column_bits(a.values))
    elif isinstance(a, pa.MapArray):
        parts.append(np.asarray(a.offsets).view(np.int32).tobytes())
        parts.append(column_bits(a.keys))
        parts.append(column_bits(a.items))
    elif isinstance(a, pa.StructArray):
        for i in range(a.type.num_fields):
            parts.append(column_bits(a.field(i)))
    elif a.type in (pa.float64(), pa.int64()):
        parts.append(np.asarray(a).view(np.uint64).tobytes())
    elif a.type == pa.bool_():
        parts.append(np.asarray(a).view(np.uint8).tobytes())
    else:
        parts.append(b'\x00'.join(x.encode() if x is not None
                                  else b'<null>' for x in a.to_pylist()))
    return b'|'.join(parts)


def assert_identical(spec, episode_or_rows, episode_id=0, catalog=None):
    """Encode the same rows/episode through both paths; compare bytes."""
    if hasattr(episode_or_rows, 'row_count'):   # real OwnedNativeEpisode
        episode, rows = episode_or_rows, None
    else:
        rows, episode = list(episode_or_rows), make_episode(episode_or_rows)
    oracle_rb = oracle_record_batch_from_episode(spec, episode, episode_id) \
        if rows is None else oracle_record_batch(spec, rows, episode_id)
    native_rb = native_record_batch(spec, episode, episode_id,
                                    catalog=catalog)
    assert oracle_rb.schema.equals(native_rb.schema), spec.name
    assert oracle_rb.num_rows == native_rb.num_rows
    for name in oracle_rb.schema.names:
        a, b = oracle_rb.column(name), native_rb.column(name)
        assert column_bits(a) == column_bits(b), f'{spec.name}.{name}'
```

(`oracle_record_batch_from_episode` drives `NativePhysicalSource` on the native episode with a tiny `batch_rows` — e.g. 7 — and reassembles the oracle RecordBatch by chunking; write it as: collect `TableBatch`es via `source.tables(batch_rows=7)`, `pa.concat_batches` the `arrow_batch` of each. This keeps the oracle exactly on the production Python path.)

```cpp
    Piece out;                                     // scalars
    if (name == "time_s" || name == "interval_end_s" || name == "dt_s") {

        out.d.reserve(rows.size());
        for (const auto &s : rows) out.d.push_back(

        out.d.insert(out.d.end(), v.begin(), v.end());
        out.offsets.push_back(static_cast<std::int32_t>(out.d.size()));
```

```python
"""Plan compiler + Arrow assembler for the native recording encoder."""
def compile_plan(spec, all_roots=None):
    """TableSpec -> plain-data plan; None when a dtype is not covered yet.

    ``all_roots`` (the catalog's claimed channel roots) is required for
    channels specs — the projector enforces unknown-root rejection with it.
    """
    if spec.kind in ('physics', 'forces'):
        return {'table': spec.name, 'kind': spec.kind}
    if spec.kind == 'channels' and all_roots is None:
        raise ValueError('channels plans require all_roots')
    return None  # channels land in Tasks 3-5

_SCALAR = {'double': 'scalar', 'bigint': 'scalar', 'boolean': 'scalar',
           'varchar': 'scalar'}

def _assemble(node_dtype, piece, pa):
    """Piece dict -> pa.Array for one catalog column."""
    kind = piece['kind']
    if kind == 'scalar':
        import numpy as np
        raw = piece['data']
        # strings stay Python lists; numeric buffers are numpy already
        data = raw if node_dtype == 'varchar' else np.asarray(raw)
        if node_dtype == 'boolean' and getattr(data, 'dtype', None) != bool:
            data = np.asarray(data).astype(bool)
        mask = None
        if piece.get('valid') is not None:
            mask = ~np.asarray(piece['valid'], dtype=bool)
        return pa.array(data, type={
            'double': pa.float64(), 'bigint': pa.int64(),
            'boolean': pa.bool_(), 'varchar': pa.string()}[node_dtype],
            mask=mask)
    if kind == 'list':
        import numpy as np
        flat = piece['data']

def pieces_to_arrow(spec, row_count, pieces, episode_id, pa):
    from bike_sim.recording.schema import column_types, arrow_type
    expected = column_types(spec)
    names, arrays = [], []
    by_key = {f.key: f for f in spec.keys + spec.fields}
    for name in expected:
        if name == 'episode_id':
            arrays.append(pa.array([episode_id] * row_count, type=pa.int64()))
        else:
            arrays.append(_assemble(by_key[name].dtype, pieces[name], pa))
        names.append(name)
    return pa.RecordBatch.from_arrays(arrays, names=names)
```

```python
_LEAF_DTYPES = {'double','bigint','boolean','varchar',
              'double[]','bigint[]','varchar[]'}

def compile_plan(spec, all_roots=None):
    if spec.kind in ('physics','forces'):
        return {'table': spec.name, 'kind': spec.kind}
    if all_roots is None:
        raise ValueError('channels plans require all_roots')
    columns, masks = [], []
    for f in spec.fields:
        if f.dtype not in _LEAF_DTYPES:
            return None
        columns.append({'name': f.key, 'dtype': f.dtype,
                        'path': list(f.path), 'optional': f.optional})
    from bike_sim.recording.schema import parent_masks
    seen = {}
    for m in parent_masks(spec):
        base = m[2:].rsplit('_',1)[0]
        seen.setdefault(base, {})
    # emit one mask entry per parent path per op
    for f in spec.fields:
        for depth in range(1, len(f.path)):
            p = f.path[:depth]
            masks += [{'name': '__'+'.'.join(p)+'_present', 'path': list(p), 'op':'present'},
                      {'name': '__'+'.'.join(p)+'_valid',   'path': list(p), 'op':'valid'}]
    for root in sorted(spec.claims):
        masks += [{'name': '__'+root+'_present','path':[root],'op':'present'},
                  {'name': '__'+root+'_valid',  'path':[root],'op':'valid'}]
    # dedupe while preserving order
    out, have = [], set()
    for m in masks:
        if m['name'] not in have: have.add(m['name']); out.append(m)
    return {'table': spec.name, 'kind': 'channels',
            'roots': sorted(spec.claims), 'all_roots': list(all_roots),
            'columns': columns, 'masks': out}
```

## Notes for the executor

- **Bitwise doubles**: `Wire` stores `double`; copying into `Piece::d` is bit-exact. Never round/format. `dt_s` is computed the same way on both sides (`end_time_s - time_s`).
- **Row order**: `forces` iterates `sample->forces` (the `ForceComponents` vector) — same order as Python's dict from `wire_object_to_python`. `map<K>` iterate the `WireObject` pair order — same as Python dict order. Do not sort.
- **Where finalize time actually goes today** (measured): `encode_rows` `forces` ≈8.5 s + `channel_drive` ≈7 s per 25k rows, `arrow_batch` `forces` ≈6 s, full channel-tree boxing ×2 (derived events + canonical), 22.5k `derived_transition` values JSON. `validate_database` on the published DB is 0.2 s — do not "optimize" it.
- **If a table regresses**, `compile_plan` returning `None` is the escape hatch — do not force it; find the divergence in `column_bits` output first (the assert message names the column).
