# План: проверки фактов по решениям симуляции

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Цель.** Проверить по первоисточникам пять утверждений, на которых держатся решения из
`docs/agents/simulation-decisions.md`:

1. как устроена муфта свободного хода у моторов в каретке;
2. реальны ли пределы модели;
3. верны ли шесть запретов;
4. есть ли данные для шин 2.8";
5. какую просадку даёт подвеска по умолчанию.

По каждой проверке получается отчёт с выводом и ссылками. Модель в этом плане не меняется.

**Устройство.** Каждая задача — отдельное исследование со своим отчётом в `docs/research/`. Отчёт показывают
пользователю. Только после его решения меняется соответствующая запись в `docs/agents/simulation-decisions.md`.
Задачи независимы и могут идти в любом порядке, но не больше трёх одновременно.

**Инструменты.** Поиск в интернете (WebSearch/WebFetch), чтение кода (`rg`, `sed`), Markdown. Сборка нужна только в
задаче 5, и только после разрешения пользователя.

**Исходный документ.** `docs/agents/simulation-decisions.md`, пункты «Решено — не сделано» 1, 4, 5, 6, 9 и запреты
36–41. Если файла ещё нет, сначала выполни `docs/superpowers/plans/2026-11-05-simulation-decisions-doc.md`.

## Общие ограничения

- **Интернет** разрешён пользователем 2026-11-05 только для этих проверок.
  - Брать первоисточники: руководства и сервисные документы производителей, патенты, рецензируемые статьи,
    стандарты.
  - Форумы и обзоры годятся только как подсказка, где искать, и выводом не считаются.
- **Параметры мотора Bosch** (момент, мощность, задержка, коэффициенты режимов) в интернете не искать: этот запрет
  пользователя от 2026-10-03 действует. Устройство передачи (где стоят муфты) проверять можно.
- **Источники.** У каждого вывода — ссылка (URL, документ, страница) и дата обращения. Если источник не найден, так
  и написать: «не найдено».
- **Ничего не менять в модели.** Не трогать код, конфигурации, тесты и эталонные записи. Новые числа предлагаются в
  отчёте, а не применяются.
- **Язык отчётов** — русский, простой, без жаргона. Числа даются с единицами.
- **Отчёты сначала смотрит пользователь**, и только после его решения правится `simulation-decisions.md`.
- **Коммит** — только по просьбе пользователя.
- **Бюджет тестов: 0 минут** в задачах 1–4. В задаче 5 возможна одна сборка (около 10 ГБ, долго) и один короткий
  прогон, но только с разрешения пользователя.
