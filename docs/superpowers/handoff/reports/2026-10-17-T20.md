Platform policy is `spawn` on Linux and retained `fork` on Darwin. Batch was
already spawn-based and remains so. User BLAS/thread environment settings are
reported, not changed. Default CLI behavior is unchanged except the intended
Linux process-start policy; explicit zero/negative job counts are rejected
before spec/output side effects.

Queue message tuples, sequence numbers, raw payloads and the existing publisher
remain unchanged. `AsyncPublicationError` is a `RuntimeError` carrying only
the successful prefix for parent application. Transport failure preserves
unacknowledged raw periods for ordered local publication; publication errors
remain errors. Recovery bookkeeping fixes source-demonstrated loss/duplication
risks without editing publication math, physics timing or controller laws.

Shutdown closes resources without flushing, publishing or stepping. Owners
retain the existing external-boundary guard and explicit flush/drain paths.
Graceful/terminate/kill joins each have a timeout; later cleanup failures add
notes without replacing the original process error or interrupt.
