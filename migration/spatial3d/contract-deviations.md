# Spatial W00–W05 contract deviations

Source-authoring observations, **pending V00/V01 review**. These are not execution
evidence or an approval of a changed physical contract. Legacy paths are unchanged.

| date | W-task | header | deviation | proposed C10 change |
|---|---|---|---|---|
| 2026-10-23 | W00/W05 | `spatial/config.hpp` | W05 requires finite positive grid-step validation, but the sketch has no owned fields for accepted grid overrides. | Freeze optional `TerrainRequest3d::dx_m/dy_m`; preserve them in exact-key terrain wire. Imported assets do not silently acquire generation defaults. V01 covers rejection and round trip; W06/W08 consume overrides. |
| 2026-10-23 | W00/W05 | `spatial/config.hpp` | An uninitialized `variant<string,Vec3>` produces an empty mount string, conflicting with the C1 `site_BB` default. | Initialize `mount_pos` to `site_BB`; V01 verifies default and explicit forms. |
| 2026-10-23 | W05 | `spatial/config.hpp`, `spatial/config.cpp` | `max_asset_bytes` owns uint64 storage, while the public TOML integer format is signed 64-bit; accepting larger values would break an otherwise valid typed-config round trip. | Freeze the accepted domain as `[1, INT64_MAX]` at both source and wire boundaries; retain uint64 storage and the existing default. V01 checks rejection and field-path diagnostics. |
| 2026-10-23 | W05 | `configuration/profile_writer.cpp` | The existing writer projects only the legacy FieldDecl table and would silently drop a new extension even when `to_value` preserves it. | Use the owning `to_value(config)` projection; its planar branch remains the original legacy projection. V01 checks public TOML round trip including nondefault hashes and bootstrap fields. |
| 2026-10-23 | W05 | `configuration/paths.cpp`, `load.hpp` | The shared resolver serves setup/research callers as well as `load_physics`; adding relative spatial terrain resolution only to the latter would yield inconsistent asset identity. | Extend the existing resolver once for `spatial_3d.terrain.path`; preserve empty paths and let the parser reject invalid request shape. This step never reads or generates the referenced asset. |
| 2026-10-23 | W00/W42 | `runtime/spatial_checkpoint.hpp` | Unqualified elaborated class names in the sketch would create new types in `runtime::spatial`. | Bind the API to the existing `::runtime::RuntimeIdentity` and `::runtime::NativeRideRuntime`; no duplicate runtime owner. |
| 2026-10-23 | W00/W41 | `recording/catalog.hpp` | The existing catalog declares `TableSpec`, not `TableDescriptor`. | Add a type alias and versioned overloads; keep existing overloads and table layouts unchanged. |
| 2026-10-23 | W00/W46 | `viewer/camera.hpp` | The named header is absent; the actual `Camera` class is in `viewer/render_owner.hpp`. | Create a forwarding header and add the spatial update declaration to the real class; implementation belongs to W46. |
| 2026-10-23 | W00/W42 | `runtime/spatial_checkpoint.hpp` | A default-deleter `unique_ptr<CheckpointStage>` cannot be destroyed by a caller that only sees the opaque declaration. | Freeze `CheckpointStageDeleter` and `CheckpointStageOwner` and return that owner. W42 defines the deleter with the complete staged type. |
| 2026-10-23 | W00/W29 | `tests/spatial/support/startup_fixture.hpp` | An owning `RigModel` with raw engine pointers and a destructor would remain copyable and could double-delete the engine. | Freeze deleted copy operations and declared noexcept move operations; W29 implements the move/destruction contract. |
| 2026-10-23 | W00/W25 | `pneumatic3d/model.hpp`, `writers/pneumatic_3d_tire.hpp` | The frozen `evaluate`/`try_compute_into` signatures have no physical interval identity; duplicate advance cannot be distinguished from the next identical input. | Retain prescribed W00 signatures; V00/C10 must select explicit interval input or a documented interval owner before W25 runtime acceptance. No duplicate-advance guarantee is claimed here. |
| 2026-10-23 | W00/W24 | `pneumatic3d/brush.hpp`, `bristles.hpp` | Brush calls do not receive a surface table to resolve `surface_id` to the local friction coefficients required by W24. | Retain prescribed declarations; V00/C10 must settle immutable surface ownership and thread-safe coefficient access before brush implementation is qualified. |
| 2026-10-23 | W00/W23 | `pneumatic3d/brush.hpp` | The fast-brush signature exposes only patch frames and point velocities, omitting the explicit camber/axle/spin inputs required by the stated camber power law. | Retain prescribed declaration; V00/C10 must define and propagate the missing wheel inputs. No camber-force implementation or qualification is included in W00–W05. |
| 2026-10-23 | W05/W17 | `runtime/project_config.hpp` | The current `RuntimeConfig` and bootstrap decoder are planar-only; producing a live runtime2 through the existing projection would require later topology/state owners or a planar surrogate. | Add `bike::io::Value runtime::project_spatial_runtime_envelope(const bike::configuration::SimulationPhysicsConfig&, const bike::io::Value& resolved_fields)` as a model-independent authoring adapter. Existing live projection explicitly rejects unavailable spatial execution. |
| 2026-10-23 | W05/W25 | `writer_config.hpp` | The existing `WriterConfig` cannot own a pneumatic3d writer, whose typed coefficient contract is produced in W25. | Add `void nativecfg::validate_spatial_writer_envelope(const bike::io::Value&)` for strict integer schema3 and exact spatial metadata. It never coerces schema3 to a planar writer or invokes the old pneumatic parser. |
