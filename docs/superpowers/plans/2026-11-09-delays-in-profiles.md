## Правила

1. Каждая задержка, такт и сглаживание, влияющие на физику или управление во время езды, — обязательное поле
   профиля, без значения по умолчанию в коде, в одном месте.
2. Задержка и такт кратны такту цикла, который их отсчитывает; такт цикла кратен шагу физики (1,25 мс). Некратное
   значение профиль не принимает.
3. Сглаживание не короче двух тактов цикла, в котором считается.
4. Ограничение скорости изменения — поле профиля; правило кратности к нему не относится.
5. Числа не меняются, меняется только место и проверка. Исключение — удаление дубля `torque_slew_nm_s`.
6. Эталоны, которые разойдутся из-за новых полей, не перезаписываются здесь: общая перезапись позже. Новые
   красные тесты должны быть только такими; список красных до плана —
   `/Volumes/SSD_1TB_M2/work/tmp/2026-11-09-reds-final/all_reds_70976032.txt` (30).
